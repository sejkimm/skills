A compact example of the wiki sidebar template

Audience

Skill authors who need a readable generated guide

Objectives
  • Separate semantic guide content from presentation
  • Use sidebar chapters for document-style navigation
  • Keep accent color restrained
Prerequisites
  • Basic JSON
  • Basic HTML structure

Semantic Envelope

Start with stable meaning. The renderer should decide how that meaning appears.

1

Content is not layout

The JSON describes teaching intent.

The model writes what the reader should learn, not CSS or hand-authored HTML.

  • Chapters define the reading path
  • Sections define the concepts
  • Components keep examples, tables, code, and checks structured
Renderer boundary

The visual system can change without rewriting the educational content.
